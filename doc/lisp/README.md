# doc/lisp

Les fichiers Lisp de ce dossier sont des exemples de la documentation de
refrains. Comme la documentation, ils sont placés sous licence
[Creative Commons Attribution 4.0 International (CC BY 4.0)](../LICENSE),
et non sous la licence GPL-3.0-only du code de refrains. Chacun porte en
en-tête son auteur et la ligne `SPDX-License-Identifier: CC-BY-4.0` ; un test
de refrains (`doc-lisp-license`) le vérifie.

- [refrains-trees.lisp](refrains-trees.lisp) : les arbres des fonctions de
  refrains, présentés dans l'exemple
  [Arbres de refrains](../exemples/arbres-des-fonctions.md).
- [neuromuse-graphs.lisp](neuromuse-graphs.lisp) : les réseaux de neurones de
  neuromuse étudiés comme graphes, présentés dans l'exemple
  [Arbres de réseaux de neurones](../exemples/neuromuse.md).
