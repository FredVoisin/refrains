# Contrastive analysis: marks and resemblance

[Examples](../examples.md) · En français : [Analyse contrastive : marques et ressemblance](../exemples/analyse-contrastive.md)

Frédéric Voisin, 2010-2013.

*An analysis kept with its data in the [fv-morphologie](https://github.com/FredVoisin/fv-morphologie) repository; its principle is summarized here, to be rewritten as a Common Lisp example.*

`mark-list` can treat segments that are not strictly identical but close in
edit distance as one motif, with `:seg-test` (see [3.1](../refrains.md#31-enumerate)).
